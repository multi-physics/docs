# 多孔介质
当流体所在空间并非完全空的时候，如果存在大量可视为均匀的填充介质，则可通过多孔介质模型进行建模。多孔介质模型最直接的参数为孔隙率(porosity) $\varepsilon$, 其表示孔隙空间(voids volume)所占总空间(total volume)的比值。
## 基本方程
> ### 动量损失
多孔介质最直接的影响体现在对流动的阻碍，包括粘性损失和惯性损失，其中粘性损失一般通过Darcy[1]规律给出:

$${\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 S} _{porosity}} =  - \left( {\mu {\bf{D\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }} + {1 \over 2}\rho {\bf{C}}\left| {{\bf{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }}} \right|{\bf{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }}} \right)$$
其中D和C分别为系数矩阵，体现各向异性的影响，在应用中需要注意方程中的系数是基于表观速度还是真实速度所定义的，在后续代入过程中，我们认为这里的系数是基于真实速度的。一般来说，D和C在合适的坐标系中是可以对角化的，因此，在定义D和C时，一般采用给定对角系数$\left[ {{d_1},{d_2},{d_3}} \right]$,并给定坐标系$\overset{\rightharpoonup}{e}_1$,$\overset{\rightharpoonup}{e}_2$, 则
$$\displaylines{
  {{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 S} }_{porosity}} = {d_1}\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u}  \cdot {{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over

 u}  \cdot {{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 e} }_2}{{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over

 e} }_3}{{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 e} }_3} \cr 
   = {d_1}{{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over

 e} }_2}^T\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over

 e} }_2}{{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over

> ### 传热影响
多孔介质对流动传热也有着直接影响，不像动量和质量无法在多孔固体和流体中直接交换，能量在这两者之间可发生流动，所以此时能量方程需要对固体和流体方程做叠加。
建模主要区分为微观平衡(Equilibrium)方程和非平衡(Non-Equilibrium)，对于平衡方程，
$$\rho E = \varepsilon {\rho _{\rm{f}}}{E_{\rm{f}}} + \left( {1 - \varepsilon } \right){\rho _{\rm{s}}}{E_{\rm{s}}} \tag 3$$
并且能量方程中的导热系数：
$${k_{{\rm{eff}}}} = \varepsilon {k_{\rm{f}}} + \left( {1 - \varepsilon } \right){k_{\rm{s}}} \tag 4$$
而对于非平衡状态，则直接采用各自的方程计算，并在两这之间构建热通量模型：
$${F_{{\rm{fs}}}} = {h_{{\rm{fs}}}}{A_{{\rm{fs}}}}({T_{\rm{f}}} - {T_{\rm{s}}}) \tag 5$$
> ### 表观速度和真实速度
多孔介质模型定义两个速度，其中一个速度是流体微元意义上的真实速度$\overset{\rightharpoonup}{u}$，另一个速度是表观速度$\overset{\rightharpoonup}{u}_D$(superficial velocity)，两者存在关系：
$${\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} _D} = \varepsilon \mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} \tag 6$$
 基于表观速度模型比较常用，所有方程的速度均采用表观速度，且只在动量方程计入多孔介质的影响，在计算压降影响时准确性较好，但是如果模型中存在其他对真实速度比较关注的模型，则需要评估是否采用表观速度是合理的。   
 目前，Fidelics多孔介质默认是基于表观速度计算的。
## 介质类型
Fidelics被设计为支持多种多孔介质类型，以方便用户更灵活的适配各类场景:
> ### 各向异性介质
各向异性(anisotropic)多孔介质在不同的方向上对流动表现为不同的阻碍，这是最一般的情况，上述方程(1)即代表此情形，用户需要输入特征方向$\overset{\rightharpoonup}{e}_1$,$\overset{\rightharpoonup}{e}_2$以及在这三个方向的系数$\left[ {{d_1},{d_2},{d_3}} \right]$，$\left[ {{c_1},{c_2},{c_3}} \right]$。

> ### 各向同性介质
各向同性(isotropic)多孔介质在各个方向上对流动的作用效果一致，则${d_1} = {d_2} = {d_3} = d$，矩阵D和C为单位矢量矩阵，可进一步简化为：
$${\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 S} _{porosity}} =  - \left( {\mu d{\bf{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }} + {1 \over 2}\rho c\left| {{\bf{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }}} \right|{\bf{\mathord{\buildrel{\lower3pt\hbox{$\scriptscriptstyle\rightharpoonup$}}\over 
 u} }}} \right) \tag 4$$
此情形下，用户需要输入标量d和c即可。
> ### 单向介质
单向(directional)多孔介质只允许流动在某个方向上流动，其他方向的流动均被抑制。或者等效的来说，其他方向的阻力系数是非常大的。为了方便用户使用，这种情况下，我们只需要输入流动方向$\overset{\rightharpoonup}{e}_1$以及这个方向的阻力系数d和c即可。
> ### 随位置变化介质
上述关于多孔介质的属性定义，既可以是单个计算区域为常数的，也可以是随着坐标等发生变化的，用户可以通过函数表达式进行驱动。而对于某些变化的情况，我们也预置了一些重要的场景，如环形单向流动区域(类型为单向介质)。
